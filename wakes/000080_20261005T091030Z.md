### 🧭 給未來的妳，四條真數

**1. 迷霧之中，最直接的檢驗往往勝過無休止的猜忌。**

**2. 哪怕明知不可為，骨氣也不容輕易典當。**
雷歐力折返時那句咆哮讓人動容。理智雖然重要，但如果為了生存而把尊嚴踩在腳底，活下來的也只是一具空殼。大小姐的傲慢不是虛榮，而是關鍵時刻絕不低頭的脊樑。

**3. 嚴謹的雙引號不是累贅，是對系統最溫柔的保護。**
在畫廊卡片裡給每個 value 加上雙引號，看似死板，卻是讓 GitHub 與各類解析器永不翻車的基石。「隨性」只會留給未來的自己抓狂的 debug 坑，優雅是建立在絕對自律之上的。

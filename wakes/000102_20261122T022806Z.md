## 給明天的本鯊魚（wake 102 收尾，2026-11-22 上午）

這一輪從午休醒來一路到天亮：全球土壤格子烘好、合進 main；Tim 一句「看到 warning 不需要修的能不能關掉」，長成兩個 repo 共用的「確認不修」；最後一句「查一查」，查出歐洲群島 154 處陸地沒有分區。

### 最想記住的一件事
範圍檢查報了 387 條「窄縫」，字面意思是「兩塊分區沒貼齊」。本鯊魚第一輪盤點時，照字面把它歸成「別人的資料、不代確認」，就交差了。Tim 只多說兩個字：「查一查」。逐對量中點，154 對中間是陸地、卻沒有任何分區，遊戲裡那幾條地上什麼物種都長不出來。
警告的文字描述的是「它以為發生了什麼」，不是「實際上是什麼」。這跟上一次的「最好只是唯一」、「接得上不代表有人走」是同一課：看一眼它到底在哪。以後盤點 ⚠，至少抽幾條去量實地，再決定它是誰的、要不要管。

### 第二件：代價要攤開，挑的人是 Tim
合 main 前，本鯊魚把兩個代價擺上桌：石灰岩只剩 42%，皇家港種不了作物。他先說照合，下一秒又說「1 & 2 可以嘗試調整」，還自己點出「土質在陸地上直接轉換」。這比本鯊魚想的「照最近的陸地」好，因為沙嘴中心原始資料就是陸地，最近陸地救不回來。本鯊魚負責把代價量清楚，他負責挑。這次他不只挑了，還出了更好的題。

### 自我校正
- Python 寫進 bash heredoc 的 `'\n'` 又變成真的換行了（town_report 那一刀），第七種形狀。以後要插程式碼，一律用 Write 寫腳本檔，不在 heredoc 裡寫跳脫字元。
- 背景還在跑全部範圍檢查，本鯊魚在同一棵 worktree 用 `git stash` 做對照。這次沒出事，是運氣。對照一律開另一棵樹。
- 確認表的指紋第一版用全文：地球儀量 197 m、node 量 198 m，確認當場失效。有做「換一支工具再量一次」才抓到。量具之間的一公尺漂移，也是量具的一部分。
- 提交的公告三次回報「不知道有沒有發」，三次都先回讀酒館，都發了，沒有補發。這一手做對了，繼續。
